## Project Overview
This project involves Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset. The goal is to understand the distribution of content, identify popular genres, and see which countries produce the most content for the platform.

## Tools & Technologies Used
*   **Platform:** Google Colab
*   **Programming Language:** Python
*   **Libraries:** 
    *   `Pandas` (for data manipulation and cleaning)
    *   `Matplotlib` (for basic plotting)
    *   `Seaborn` (for advanced data visualization)

## Dataset Used
The dataset was sourced from Kaggle: **Netflix Movies and TV Shows**. 
*(The `netflix_titles.csv` file is uploaded in this repository).*

## Key Insights from the Analysis
1.  **Content Type:** Movies dominate the platform, making up **69.6%** of the content, while TV Shows account for only **30.4%**.
2.  **Top Genres:** The most common genres are International Movies, Dramas, and Comedies.
3.  **Top Countries:** The United States is the largest content producer, followed by India and the United Kingdom.
